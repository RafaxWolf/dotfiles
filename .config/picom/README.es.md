# Picom

Configuración del compositor para X11 utilizado por la sesión de BSPWM.

***Idioma***
- [🇺🇸 English](./README.md)
- 🇪🇸 Español

La configuración principal está en [`picom.conf`](./picom.conf). BSPWM inicia Picom como daemon durante el arranque de la sesión.

Revisa el backend, las sombras, la opacidad y los ajustes de rendimiento antes de usarlo en otro hardware.
