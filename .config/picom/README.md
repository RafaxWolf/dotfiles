# Picom

X11 compositor configuration used by the BSPWM session.

***Language***
- 🇺🇸 English
- [🇪🇸 Español](./README.es.md)

The main configuration is [`picom.conf`](./picom.conf). BSPWM starts Picom as a daemon during session startup.

Review backend, shadow, opacity, and performance settings before using it on different hardware.
