# Fish

Fish shell configuration with aliases, Tide prompt settings, and helper functions.

***Language***
- 🇺🇸 English
- [🇪🇸 Español](./README.es.md)

## Included configuration

- `bat` and `lsd` aliases.
- Tide prompt with OS, directory, command duration, context, status, Git, Docker, and private-mode information.
- `ncat` and `netexec` shortcuts.
- Custom history expansion bindings for `!` and `$`.
- `settarget` and `cleartarget` helpers.

The target helpers currently write to a machine-specific path. Update that path before using them elsewhere.
