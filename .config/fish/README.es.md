# Fish

Configuración de Fish con alias, ajustes del prompt Tide y funciones auxiliares.

***Idioma***
- [🇺🇸 English](./README.md)
- 🇪🇸 Español

## Configuración incluida

- Alias para `bat` y `lsd`.
- Prompt Tide con información del sistema, directorio, duración, contexto, estado, Git, Docker y modo privado.
- Atajos para `ncat` y `netexec`.
- Atajos personalizados de historial para `!` y `$`.
- Helpers `settarget` y `cleartarget`.

Los helpers de objetivos escriben actualmente en una ruta específica del equipo. Actualízala antes de utilizarlos en otro sistema.
