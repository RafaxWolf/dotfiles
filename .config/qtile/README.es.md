# Qtile

Configuración alternativa de gestor de ventanas basada en la configuración predeterminada de Qtile.

***Idioma***
- [🇺🇸 English](./README.md)
- 🇪🇸 Español

## Características

- `mod4`/Super como tecla modificadora.
- Layouts Columns y Max.
- Nueve grupos o espacios de trabajo.
- Barra inferior con layout, grupos, prompt, título de ventana, systray, reloj y salida rápida.
- Controles de teclado para enfocar, mover, redimensionar, usar ventanas flotantes, pantalla completa, recargar y cerrar.

## Atajos principales

| Atajo | Acción |
| --- | --- |
| `Super + Enter` | Abrir el terminal detectado |
| `Super + H/J/K/L` | Mover el foco |
| `Super + Shift + H/J/K/L` | Mover ventanas |
| `Super + Ctrl + H/J/K/L` | Redimensionar ventanas |
| `Super + Tab` | Cambiar de layout |
| `Super + W` | Cerrar la ventana enfocada |
| `Super + F` | Alternar pantalla completa |
| `Super + T` | Alternar modo flotante |
| `Super + Ctrl + R` | Recargar Qtile |
| `Super + Ctrl + Q` | Salir de Qtile |
| `Super + 1..9` | Cambiar de grupo |

Edita [`config.py`](./config.py) para personalizar layouts, widgets, grupos y aplicaciones.
