# Qtile

Alternate window manager configuration based on the Qtile default configuration.

***Language***
- 🇺🇸 English
- [🇪🇸 Español](./README.es.md)

## Features

- `mod4`/Super as the modifier.
- Columns and Max layouts.
- Nine groups/workspaces.
- Bottom bar with layout, groups, prompt, window title, systray, clock, and quick exit.
- Keyboard controls for focus, moving, resizing, floating, fullscreen, reload, and shutdown.

## Main shortcuts

| Shortcut | Action |
| --- | --- |
| `Super + Enter` | Launch the detected terminal |
| `Super + H/J/K/L` | Move focus |
| `Super + Shift + H/J/K/L` | Move windows |
| `Super + Ctrl + H/J/K/L` | Resize windows |
| `Super + Tab` | Switch layout |
| `Super + W` | Close the focused window |
| `Super + F` | Toggle fullscreen |
| `Super + T` | Toggle floating |
| `Super + Ctrl + R` | Reload Qtile |
| `Super + Ctrl + Q` | Exit Qtile |
| `Super + 1..9` | Switch groups |

Edit [`config.py`](./config.py) to customize layouts, widgets, groups, and applications.
