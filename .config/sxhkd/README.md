# SXHKD

Keyboard shortcuts for BSPWM and common desktop actions.

***Language***
- 🇺🇸 English
- [🇪🇸 Español](./README.es.md)

## Main shortcuts

| Shortcut | Action |
| --- | --- |
| `Super + Enter` | Open Kitty |
| `Super + D` | Open Rofi |
| `Super + Escape` | Reload SXHKD |
| `Super + W` | Close the focused window |
| `Super + Shift + W` | Kill the focused window |
| `Super + Q` | Quit BSPWM |
| `Super + Shift + R` | Restart BSPWM |
| `Super + M` | Toggle tiled/monocle layout |
| `Super + Arrow keys` | Focus a window |
| `Super + Shift + Arrow keys` | Swap or move a window |
| `Super + 1..9, 0` | Focus desktops 1–10 |
| `Super + Shift + 1..9, 0` | Send a window to a desktop |
| `Super + T` | Tiled state |
| `Super + Shift + T` | Pseudo-tiled state |
| `Super + S` | Floating state |
| `Super + F` | Fullscreen state |
| `Super + Alt + Arrow keys` | Resize using the BSPWM helper |

See [`sxhkdrc`](./sxhkdrc) for the complete configuration.
