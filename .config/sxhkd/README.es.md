# SXHKD

Atajos de teclado para BSPWM y acciones comunes del escritorio.

***Idioma***
- [🇺🇸 English](./README.md)
- 🇪🇸 Español

## Atajos principales

| Atajo | Acción |
| --- | --- |
| `Super + Enter` | Abrir Kitty |
| `Super + D` | Abrir Rofi |
| `Super + Escape` | Recargar SXHKD |
| `Super + W` | Cerrar la ventana enfocada |
| `Super + Shift + W` | Forzar el cierre |
| `Super + Q` | Salir de BSPWM |
| `Super + Shift + R` | Reiniciar BSPWM |
| `Super + M` | Alternar tiled/monocle |
| `Super + Flechas` | Enfocar una ventana |
| `Super + Shift + Flechas` | Intercambiar o mover una ventana |
| `Super + 1..9, 0` | Enfocar los escritorios 1–10 |
| `Super + Shift + 1..9, 0` | Enviar una ventana a un escritorio |
| `Super + T` | Estado tiled |
| `Super + Shift + T` | Estado pseudo-tiled |
| `Super + S` | Estado flotante |
| `Super + F` | Pantalla completa |
| `Super + Alt + Flechas` | Redimensionar con el script de BSPWM |

Consulta [`sxhkdrc`](./sxhkdrc) para ver la configuración completa.
