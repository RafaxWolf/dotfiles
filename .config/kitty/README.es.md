# Kitty

Configuración del terminal utilizada por las sesiones del escritorio.

***Idioma***
- [🇺🇸 English](./README.md)
- 🇪🇸 Español

## Características

- Hack Nerd Font en tamaño 11.
- Colores personalizados desde `color.ini`.
- Zsh como shell predeterminada.
- Opacidad del fondo del 95 %.
- Detección de URLs y estilo curly para las URLs.
- Atajos para ventanas adyacentes, pestañas y nuevas ventanas usando el directorio actual.
- Barra de pestañas con estilo Powerline.

Edita [`kitty.conf`](./kitty.conf) para cambiar la fuente, shell, colores, opacidad y atajos.
