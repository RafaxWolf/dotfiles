# Kitty

Terminal configuration for the desktop sessions.

***Language***
- 🇺🇸 English
- [🇪🇸 Español](./README.es.md)

## Features

- Hack Nerd Font at size 11.
- Custom colors from `color.ini`.
- Zsh as the default shell.
- 95% background opacity.
- URL detection and curly URL styling.
- Shortcuts for neighboring windows, tabs, and new windows using the current directory.
- Powerline-style tab bar.

Edit [`kitty.conf`](./kitty.conf) to change the font, shell, colors, opacity, and mappings.
